## Remote Media

Remote media references:

- Marketing hero video: `https://storage.yandexcloud.net/idc-website-app/hero-preview2.mp4` in `src/app/page.tsx`.
- Pull-up landing videos in `src/app/pullups/PullupsLandingClient.tsx`.
- Exercise template videos in `src/data/exercises.ts`.
- Studio/directions media in `src/app/api/robokassa/result/route.ts`.
- Exercise library videos through Cloudflare Stream URLs generated by `src/lib/cloudflare/stream.ts`.

Mobile reuse:

- Remote exercise videos may be useful only after playback rights, performance, and CDN policy are confirmed.
- Marketing videos should not be included in student app MVP unless product requests onboarding content.
- Cloudflare Stream URLs should be exposed through student-safe APIs, not by moving Cloudflare credentials to mobile.

## Video and Image Conventions

Cloudflare Stream:

- `src/lib/cloudflare/stream.ts` builds iframe URLs and thumbnail URLs.
- New exercise uploads go through direct TUS upload initialized by server route.
- Cloudflare env vars and API token are server-only.

Yandex Cloud Storage:

- Used for marketing/exercise template videos.
- URLs are hardcoded in marketing/data files.

Mobile considerations:

- Determine whether React Native should play Cloudflare iframe URLs through WebView or use a stream URL format suitable for native video playback.
- Confirm whether thumbnails are available for every exercise.
- Define fallback state when video is missing or unavailable.
